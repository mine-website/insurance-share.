How this admin tool works

This page has no password on purpose. A website hosted on GitHub Pages cannot keep a secret, so a password here would only look secure. Instead, this page can not change your website by itself. It prepares the changes, and the changes only go live when they are saved to your GitHub repository — either by you uploading them on github.com, or by pasting a GitHub access token below. Only you (the GitHub account owner) can do that.

Optional: publish straight to GitHub from this page

Without this, you download the changed files and upload them on github.com (always works, needs no token). With this, the button "Publish to GitHub" saves everything in one click.

  1. On github.com open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Choose only your website repository, and give it Contents: Read and write permission. Nothing else.
  3. Paste the token below. It is used only from this browser and sent only to api.github.com.
